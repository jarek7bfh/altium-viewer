Altium Viewer – przeglądarka schematów i PCB Altium (PWA)

Wgraj zawartość tego folderu na dowolny hosting z HTTPS (np. GitHub Pages lub Netlify Drop),
otwórz adres w Chrome na tablecie i wybierz "Dodaj do ekranu głównego" / "Zainstaluj aplikację".

Pliki projektów nie są nigdzie wysyłane – są czytane i zapisywane tylko w pamięci przeglądarki na tablecie.
